# TechPass Summit 2026 - Event Registration & Pass System

A modern, full-stack web application built with React, Vite, React Router, and Supabase database integration for managing tech summit event registrations and workshop pass bookings.

## Features

- **Home Dashboard**: Modern glassmorphism hero interface introducing upcoming summits and direct booking actions.
- **Featured Events**: Browse available workshops, hackathons, and AI symposiums with schedule details.
- **Pass Registration**: Interactive form to select events, choose pass tiers (Student, Professional, VIP Access), and specify ticket quantities.
- **My Passes (Real-time Database)**: Fetches and displays reserved passes dynamically from Supabase database tables.

## Tech Stack

- **Frontend**: React.js (Vite)
- **Routing**: React Router DOM
- **Backend / Database**: Supabase (PostgreSQL)
- **Styling**: Custom Modern Glassmorphic CSS
